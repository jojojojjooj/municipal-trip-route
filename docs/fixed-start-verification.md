# 고정 출발지 경로 검증

카카오 로컬 주소 검색으로 **서울특별시청**을 고정 출발지로 지정한 뒤, `서울역`과 `광화문`을 출장 목적지로 등록했다. 고정 출발지는 방문 목적지 수에 포함하지 않으면서 지도 상태 패널의 `START FIXED`, 경로 요약, PDF 보고서와 출발 마커에 표시됐다.

Nearest Neighbor + 2-opt 계산은 고정 출발지를 시작점으로 두고 방문 목적지의 순서만 정렬했다. 실제 저장 결과에서 출발지 이름·주소·위도·경도와 **3.52km · 7분** 요약이 출장 계획에 함께 기록된 것을 확인했고, 저장 계획을 다시 불러온 화면에서 출발지와 두 목적지가 복원됐다. 검증용 저장 계획은 완료 후 삭제했다.

390px 모바일 완료 상태에서도 고정 출발지 카드, 두 목적지, 거리·시간·목적지 수, 최적화 상태, 방문 순서 및 출력 제어가 세로 흐름 안에서 표시되는 것을 확인했다. 고정 출발지가 포함된 PDF 다운로드도 성공 알림으로 확인했다.
