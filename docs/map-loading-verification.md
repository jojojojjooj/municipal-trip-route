# 지도 로딩 스켈레톤 검증

2026-08-21에 로그인된 출장 플래너를 새로 열어 카카오 지도 초기화 흐름을 확인했다. SDK와 타일이 준비되는 초기 화면에서는 지도 영역 크기를 유지한 채 크림색 그리드, 위치 표식, `MAP LOADING` 레이블 및 `출장 지도를 준비하고 있습니다.` 안내가 표시됐다.

지도 타일 준비 후에는 스켈레톤 오버레이가 투명 전환되고 실제 카카오 지도와 `지도를 클릭해 목적지를 추가하세요` 안내가 표시되는 것을 브라우저에서 확인했다. `prefers-reduced-motion` 환경에서는 스윕과 펄스 애니메이션을 비활성화하도록 구현했다.

모바일 전체 화면에서도 지도 영역의 높이가 유지되고, 스켈레톤의 그리드·표식·진행 안내가 입력 영역과 요약 카드 사이에서 안정적으로 표시되는 것을 확인했다. SDK 로딩 실패 시에는 스켈레톤 대신 연결 확인 안내와 오류 메시지를 보여 주도록 상태를 분리했다.

개발 환경에서 `?map-status-test=error` 쿼리로 SDK 실패를 재현했다. 브라우저에서 `지도 연결을 확인해 주세요`와 `테스트용 지도 SDK 연결 실패 상태입니다.` 오류 오버레이가 실제로 표시되는 것을 확인했다. 이 테스트 분기는 개발 환경에서만 동작한다.

오류 오버레이의 `다시 시도` 버튼을 클릭했을 때 오류 안내가 즉시 지도 스켈레톤으로 전환되고, 이전 SDK 요청이 정리된 뒤 카카오 지도 타일과 지도 클릭 안내가 다시 표시되는 것을 확인했다.
