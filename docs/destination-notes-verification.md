# 목적지 현장 메모 검증

각 목적지 카드에 최대 1,000자의 현장 메모 입력을 추가했다. `서울특별시청`의 메모를 **민원실 방문 전 담당 주무관에게 연락 · 점검표 지참**으로 수정하자, 방문 순서와 숨김 PDF 보고서의 목적지 항목에 즉시 반영되는 것을 확인했다.

메모가 포함된 왕복 계획을 실제로 저장한 뒤, `tripStops.note` 열에 두 목적지의 메모가 순서와 함께 기록됐는지 확인했다. 저장 계획을 다시 불러온 화면에서도 두 메모가 목적지 입력과 경로 요약에 복원됐다. 메모가 포함된 PDF 다운로드 흐름을 실행했으며, 검증용 계획은 완료 후 삭제했다.

390px 모바일 화면에서는 목적지 이름·주소 아래에 메모 입력 영역이 표시되고, 방문 순서 패널에 메모가 보조 정보로 표시되는 것을 확인했다.
