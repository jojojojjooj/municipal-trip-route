# 지도 연결 복원력 검증

개발 환경의 `map-status-test=error` 재현 화면에서 지도 SDK 실패 후 자동 재시도 카운트가 `1/3`으로 표시되고, 이후 지도가 정상적으로 다시 초기화되는 것을 확인했다.

브라우저 `offline` 이벤트를 전달했을 때 지도 영역은 오프라인 안내 문구와 비활성화된 `네트워크 복구 대기 중` 버튼을 표시했다. 이어 `online` 이벤트를 전달하면 지도 연결이 자동으로 재개됐다. 온라인 복구 시 이전 지도 레이어·캔버스를 정리하도록 보완한 뒤 단일 지도 인스턴스로 정상 렌더링되는 것을 재확인했다.

390px 너비의 모바일 화면에서도 초기 지도 스켈레톤 우측에 `자동 재시도 1/3` 상태가 표시되는 것을 확인했다. 오류 오버레이의 `지금 다시 시도`와 `주소 목록으로 계속` 제어는 세로로 분리해 좁은 폭에서 겹치지 않도록 조정했다.
