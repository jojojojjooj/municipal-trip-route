# 주소 목록 작업 모드 검증

지도 SDK 실패를 재현한 상태에서 `주소 목록으로 계속`을 선택했다. 중앙 작업 영역이 지도 대신 주소 목록 모드로 전환됐으며, 지도 재연결 버튼과 목적지별 방문 순서·주소·좌표·이동·삭제 제어를 제공하는 것을 확인했다.

카카오 로컬 주소 검색으로 `서울특별시청`을 조회하고 결과를 선택했다. 지도 연결 없이도 좌측 목적지 목록, 중앙 목록 작업 영역, 경로 요약 및 PDF 다운로드 버튼에 목적지가 일관되게 반영됐다. 좁은 작업 영역에서는 목록 모드가 자동 배치로 전환되어 제목과 안내 문장이 글자 단위로 분리되지 않도록 조정했다.

최종 브라우저 검증에서는 `서울특별시청`과 `서울역` 두 목적지를 추가한 뒤 **최적 방문 순서 계산**을 실행했다. 성공 알림과 함께 Nearest Neighbor + 2-opt 적용을 확인했고, 경로 요약은 **1.6km · 3분**으로 갱신됐다. 이어 `목록 모드 검증 계획`을 저장해 아카이브에 반영되는 것을 확인하고, PDF 다운로드 성공 알림과 다운로드 목록의 `undated_목록 모드 검증 계획_출장요약.pdf` 파일 생성을 확인했다. 검증용 저장 계획은 이후 삭제해 사용자 목록을 원래의 빈 상태로 복구했다.
