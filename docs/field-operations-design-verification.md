# 현장 운영 디자인 고도화 검증

왕복 완료 상태에서 출발·복귀 기준점을 **Departure Desk**로 재구성했다. 출발 노드, 출발지 주소, START 상태, 왕복 스위치, 편도·왕복 안내 문구와 복귀 구간 포함 여부가 하나의 카드 안에서 읽히는 것을 데스크톱 화면에서 확인했다.

경로 요약은 왕복 상태 배지, 복귀 구간이 포함된 총 거리, 시간·방문 목적지 지표, 준비 상태, 출발·복귀 기준점, 타임라인형 방문 순서, 다음 행동 및 출력 제어로 정리했다. 390px 화면에서는 출발지 카드와 왕복 스위치, 지표, 복귀 항목, 저장·PDF·인쇄·공유 제어가 세로 흐름에 맞춰 표시되는 것을 확인했다.
